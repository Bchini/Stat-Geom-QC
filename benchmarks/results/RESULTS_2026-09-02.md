# STAT GEOM QC 2.9.36 benchmark results

Measured on 2026-09-02 with the reproducible synthetic benchmark in this
repository.

## Headline

On this machine, the Standard profile analyzed 50,000 synthetic polygons in a
median of 2.86 seconds for the clean sparse-grid scenario and 2.95 seconds for
the controlled-overlap scenario. The second scenario injected 99 overlap pairs;
STAT GEOM QC detected all 99.

This is an analysis-engine benchmark, not an end-to-end application benchmark.
Layer loading, fixture generation, report rendering and file writing are
excluded. Synthetic results must not be presented as representative of every
real dataset.

The Standard profile produced 70 percent check coverage because the three
domain-dependent Extras checks were intentionally disabled. Coverage is not a
performance percentage and must be reported alongside the score.
